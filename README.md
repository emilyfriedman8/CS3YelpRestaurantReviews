# Yelp Sentiment Analysis Case Study

## Overview
This case study explores how text data from Yelp restaurant reviews can be used to understand and predict customer sentiment. The goal is to demonstrate a simple data science workflow, including exploratory data analysis, text feature engineering, and classification modeling.

This project is designed for a 2nd year UVA student and focuses on clear explanations and fundamental concepts rather than technical complexity.

---

## Repository Structure

- **Data/**
  - Yelp Restaurant Reviews.csv → dataset used for analysis  

- **Example EDA Outputs/**
  - Sample visualizations (rating distribution, word frequency, etc.)  

- **Sources/**
  - Background readings and supporting materials  
  - `references.md` → annotated sources used for the case study  

- **yelp_EDA_example.ipynb**
  - Example notebook demonstrating exploratory data analysis  

- **yelp_model_example.ipynb**
  - Example notebook demonstrating feature engineering and modeling  

- **CS3_Hook Document.pdf**
  - Introductory document to engage students  

- **CS3_Rubric.pdf**
  - Guidelines for completing the case study  

---

## How to Use This Case Study

1. Start with the **Hook Document** to understand the problem  
2. Review the **EDA notebook** to explore the dataset  
3. Follow the **Model notebook** to build a sentiment classifier  
4. Refer to the **Rubric** for expectations  
5. Use the **Sources** for additional context  

---

## Goal

The goal of this case study is to help students understand how text data can be transformed into meaningful insights and used to predict sentiment in real-world applications.
